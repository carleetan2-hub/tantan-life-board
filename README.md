# Tantan Life Board

记录生活、帮助个人成长的个人工作台。

## 隐私说明

**你的数据完全安全，不会泄露。**

- 所有数据保存在你设备浏览器的本地存储（localStorage）中
- 不会上传到 GitHub 或任何第三方服务器
- 仓库公开后，别人只能看到代码，无法看到你记录的任何内容
- 你的数据始终属于你，与代码完全隔离

## 跨设备同步说明

localStorage 是浏览器本地存储，**不同设备/浏览器之间的数据不会自动同步**。如果你在电脑和手机上都会使用，有以下两种方式实现同步：

### 方式一：手动导出导入（无需服务器）

1. 在电脑上：设置 → 数据管理 → 导出数据（会下载一个 JSON 文件）
2. 将文件发送到手机（微信/邮件/云盘均可）
3. 在手机上：设置 → 数据管理 → 导入数据，选择该文件

### 方式二：自动云同步（需要部署同步服务器）

1. 参照 `SERVER_DEPLOY_GUIDE.md` 部署同步服务器
2. 在工作台设置中填写服务器地址和同步密钥
3. 开启自动同步后，每次修改会自动上传到云端
4. 在手机上打开工作台，填写相同的服务器地址和密钥即可同步

> 建议方式二适合长期多设备使用，方式一适合偶尔切换设备。

## 在线使用

直接打开 `index.html` 即可使用。所有数据保存在浏览器本地，无需后端服务。

## 部署到 GitHub Pages

1. 把本仓库代码上传到你的 GitHub 仓库
2. 进入仓库 Settings → Pages
3. Source 选择 Deploy from a branch，Branch 选 `main`，文件夹选 `/ (root)`
4. 等待几分钟，访问 `https://你的用户名.github.io/仓库名/` 即可使用

## 数据备份

- **导出**：点击右上角设置 → 数据管理 → 导出数据
- **导入**：设置 → 数据管理 → 导入数据

## 技术说明

- 纯前端实现，单 HTML 文件，零依赖
- 使用 localStorage 本地存储数据
- 支持 PWA，可添加到手机主屏幕
- 响应式设计，适配手机与桌面
